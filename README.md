# Texas Dog Park Directory

Welcome to the Texas Dog Park Directory!  
This website helps dog owners find the best dog parks in Texas and provides helpful resources for safe and fun park visits.

## Features

- Directory of Texas dog parks
- Printable dog park checklist
- Tips and resources for dog owners

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/linking2success/texas-dog-parks.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser to view the site locally.

## Deployment

This site is automatically deployed with [Vercel](https://vercel.com/).
